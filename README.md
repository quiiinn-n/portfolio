# 项目1:赴澳门科技大学交流学习
## 时间：2026.01-2026.06
### 项目描述：
- 作为校际交换生赴澳门科技大学交流修读课程，主攻媒介传播、跨文化传播相关方向，系统学习跨境媒介、数字文化与新媒体传播相关理论；参与多场粤港澳传媒学术沙龙与实地文化调研活动，对比内地与港澳媒介生态差异，观察数字媒介在跨文化场景中的传播实践，拓展跨文化传播研究视野，积累多元文化环境下的媒介观察经验。
### 项目职责：
- 1、修读跨文化传播、数字媒介相关专业课程，完成课程论文、文献研读与课堂研讨任务，梳理跨境媒介传播案例；
- 2、参与粤港澳传媒学术沙龙、文化实地调研，整理沙龙纪要、调研笔记，归纳不同区域媒介传播特点；
- 3、对比分析内地与港澳媒介生态、受众传播习惯差异，结合所学理论形成个人研究观察，为毕业论文跨文化传播相关研究积累素材；
- 4、与不同背景师生开展学术交流，锻炼跨文化沟通表达能力。

# 项目2:山东省社科立项《智媒时代青少年主流价值观的媒介认同与提升路径研究》
## 时间：2025.05-2028.11
### 项目描述：
- 本项目为山东省社会科学规划新闻传播学学科唯一立项重点课题，聚焦智媒环境下青少年主流价值观媒介认同问题，探索媒介影响机制与优化提升路径。项目围绕媒介使用、文化资本、价值观认同开展实证研究，综合文献梳理、问卷调查、量化数据分析等研究方法，挖掘青少年媒介接触与价值观形成之间的内在逻辑，为相关传播策略制定提供实证依据。
### 项目职责：
- 参与课题前期论证工作，协助完成研究方案打磨；独立设计调研问卷，统筹样本发放、线上回收工作，开展原始数据清洗、分类整理；使用统计工具完成样本数据的描述统计与相关性分析；协助查阅、梳理中英文文献，归纳现有研究成果，参与搭建本课题跨学科研究分析框架，支撑课题实证部分撰写。

# 项目4:Python 网页爬取与传播数据可视化
## 时间：2022.10-2022.12
- 本项目系个人独立完成，针对《财富》世界 500 强榜单开展数据采集与分析。利用 Python 爬取网页原始榜单数据，通过 xlswriter 完成数据导出并存储至 Excel，借助 pandas 库对数据集进行清洗与校验，剔除异常值，保证数据可靠；采用 pyecharts 库绘制饼图、世界地图、柱状图等可视化图表，直观呈现企业营收、地域分布等维度特征，挖掘数据内在规律，独立完成从数据获取、清洗校验、可视化呈现到信息解读的整套数据分析工作。

# 项目6:《穹顶之下，俯仰山西》古建藻井文旅融媒体整合营销策划案-设计与撰写
## 时间：2022.03-2022.06
### 项目描述：
- 本项目聚焦山西古建藻井特色文旅资源，针对传统文化传播形式单一、受众年轻化不足等问题，开展融媒体整合营销策划。深度挖掘古建藻井文化内核，提炼专属差异化文旅IP，搭建完整的融媒体传播策略体系。融合数字化交互形式，整合海报传播、H5互动游戏、VR实景沉浸式体验等多元传播载体，打造集文化科普、文旅推广、用户交互于一体的数字化融媒体产品，创新传统古建文化的年轻化、沉浸式传播模式，助力山西古建文旅资源破圈传播。
### 项目职责
- 负责项目整体策划与数字化内容落地，系统梳理山西古建藻井文旅资源，完成文化IP差异化定位与整体传播策略搭建；独立设计制作系列文旅宣传海报，搭载传播二维码拓宽线上传播渠道；自主策划并制作轻量化H5互动小游戏，增强用户趣味性与参与度；结合VR实景技术打造沉浸式观赏场景，还原古建藻井风貌；整合多元融媒体传播形式，统筹完成整套策划方案与数字化产品落地，实现传统文化的现代化、数字化创新传播。
